# Full Stack Open: React Native

Rate Repository App, in `rate-repository-app/`.

## Try it with Expo Go

![QR code](qr.png)

## Run locally

```bash
cd rate-repository-app
npm install
npm start
```

Needs the [rate-repository-api](https://github.com/fullstack-hy2020/rate-repository-api) running; set its URL in `rate-repository-app/.env` (`EXPO_PUBLIC_APOLLO_URI`).
